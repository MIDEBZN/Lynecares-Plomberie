# SEO Action Plan

## Critical Priority (Fix Immediately)
- **None.** The site is in excellent technical health and follows core best practices.

## High Priority (Fix within 1 week)
1. **Schema Enrichment:** Add `image` and `logo` properties to the `Plumber` JSON-LD schema on the homepage. This increases the chance of displaying a rich knowledge panel in search results.
2. **Sitemap & Robots Verification:** Ensure `sitemap.xml` is automatically generated by Astro and submitted to Google Search Console. Include a reference to it in the `robots.txt` file (e.g. `Sitemap: https://www.plomberieliegeoise.be/sitemap-index.xml`).

## Medium Priority (Fix within 1 month)
1. **Self-Host Fonts:** Download the "Inter" Google Font and host it locally in the `/public` folder or via Astro's font integrations to improve LCP (Largest Contentful Paint) and reduce external DNS lookups.
2. **AI Crawler Optimization (llms.txt):** Add a `/llms.txt` file to the root of the site containing a markdown-formatted summary of your business, services, pricing, and contact info to feed facts directly to AI search engines (ChatGPT, Perplexity, Claude).

## Low Priority (Backlog)
1. **Security Headers:** Verify the implementation of strict security headers (HSTS, X-Content-Type-Options) in the hosting configuration (e.g., `vercel.json` if hosted on Vercel).
